## 🔧 Customization Guide

### Change Colors
Edit in `index.html`:
```javascript
tailwind.config = {
  theme: {
    extend: {
      colors: {
        'sinar-gold': '#D4AF37',        // Your color here
        'sinar-gold-light': '#F4E4A6',  // Your color here
        'sinar-dark': '#0A0A0A',        // Your color here
        'sinar-dark-light': '#1A1A1A',  // Your color here
      }
    }
  }
}
```

### Change Content
Edit component files in `src/components/`:
- Portfolio projects in `PortfolioSection.jsx`
- Testimonials in `TestimonialsSection.jsx`
- Division info in `DivisionsSection.jsx`
- etc.

### Add Real Images
Replace emoji icons with `<img>` tags:
```jsx
// Before
<div className="text-7xl">🌐</div>

// After
<img src="/path/to/image.jpg" alt="Project" />
```

### Connect Form
In `ContactSection.jsx`, replace simulated submission:
```javascript
// Replace setTimeout with real API call
const handleSubmit = async (e) => {
  e.preventDefault()
  setIsSubmitting(true)
  
  try {
    const response = await fetch('YOUR_API_ENDPOINT', {
      method: 'POST',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify(formData)
    })
    
    if (response.ok) {
      setFormStatus('success')
      setFormData({ name: '', email: '', message: '' })
    }
  } catch (error) {
    setFormStatus('error')
  } finally {
    setIsSubmitting(false)
  }
}
```
