# SinarAI System - Company Portfolio Website

A modern, calming, and futuristic company portfolio website for **SinarAI System** - a visionary company that operates using Artificial Intelligence as its workforce.

## 🌟 About SinarAI System

**SinarAI System** is a futuristic company that uses AI as the workforce to create digital solutions like websites, content, and automation systems. The company doesn't build AI — it uses AI as employees, all guided by human values.

### Core Philosophy
> "AI-Driven Work. Human Values."

SinarAI believes that technology should help humans work smarter, not replace them.

## ✨ Features

- **Modern & Minimalistic Design** - Clean, elegant interface with dark theme and golden accents
- **Smooth Animations** - Subtle, intentional animations using custom CSS
- **Fully Responsive** - Works perfectly on all devices
- **Interactive Components** - Engaging UI elements with hover effects
- **Static Data** - All content is hardcoded for easy testing and demonstration

## 🎨 Design Philosophy

- **Style**: Calm futuristic minimalism (Think: Apple meets OpenAI meets Notion)
- **Colors**: Dark background (#0A0A0A) with warm golden accents (#D4AF37, #F4E4A6)
- **Typography**: Inter for body, Space Grotesk for headings
- **Animation**: Soft, slow-paced, intentional movements
- **Feel**: Intelligent yet human, trustworthy yet innovative

## 📋 Sections

1. **Hero Section** - Eye-catching introduction with animated background
2. **About Section** - Explanation of SinarAI's unique approach
3. **Vision & Mission** - Company goals and values
4. **Our Divisions** - Three specialized studios:
   - Creative Studio (Content & Design)
   - Web & System Studio (Websites & Automation)
   - Document & Task Studio (Reports & Productivity)
5. **Portfolio** - Showcase of example projects
6. **Testimonials** - Client feedback
7. **Contact** - Interactive contact form
8. **Footer** - Complete site navigation and information

## 🚀 Getting Started

### Prerequisites
- Node.js (v14 or higher)
- npm or yarn

### Installation

1. Install dependencies:
```bash
npm install
```

2. Run the development server:
```bash
npm run dev
```

3. Open your browser and navigate to the local URL shown in the terminal (usually `http://localhost:5173`)

### Build for Production

```bash
npm run build
```

## 🎯 Key Functionalities

### Navigation
- Smooth scrolling to sections
- Mobile-responsive hamburger menu
- Fixed header with transparency effect on scroll

### Portfolio Filter
- Filter projects by category (All, Web, Content, Automation)
- Smooth transition effects

### Contact Form
- Form validation
- Loading state during submission

- Floating elements

- Smooth page transitions
